Mini embedded Linux project

Turn an LED On/Off with Raspberry Pi 5

This is the first physical computing project: a Raspberry Pi GPIO pin acts like a controllable switch. When the pin is HIGH, the LED lights. When it is LOW, the LED turns off.

Parts Wiring GPIO pinout

1. Parts you need

Part Quantity Purpose
Raspberry Pi 5 1 The Linux board that controls the GPIO pin.
LED 1 The output device.
220Ω resistor 1 Limits current through the LED and protects the GPIO pin.
Breadboard 1 Makes wiring easier without soldering.
Male-female jumper wires 2 Connect Raspberry Pi GPIO pins to the breadboard.
Do not connect an LED directly to a GPIO pin without a resistor. The resistor is not decoration; it limits current. Think of it as a small speed limit for electricity.

2. Wiring

We will use GPIO17, which is physical pin 11. For ground, use physical pin 6.

Connection Raspberry Pi 5 pin Breadboard / LED side
GPIO output GPIO17 / physical pin 11 220Ω resistor → LED long leg/anode
Ground GND / physical pin 6 LED short leg/cathode

Simple schema

Raspberry Pi 5 Breadboard / LED --------------------------------------------------------------- Physical pin 11 / GPIO17 ---- 220Ω resistor ---- LED long leg (+) Physical pin 6 / GND -------------------------- LED short leg (-)
The long LED leg is usually the positive side/anode. The short LED leg is usually the negative side/cathode and goes to GND.

3. Where to find the Raspberry Pi 5 GPIO pin schema

Option A: On the Raspberry Pi itself

Run this in the terminal:

pinout

This prints a GPIO reference directly in the terminal. It is very useful when working through SSH.

Option B: Interactive website

Use pinout.xyz. It is an interactive Raspberry Pi GPIO reference and shows GPIO, power, ground, I²C, SPI, UART, PWM, and more.
